    • Heidelberg files hold patient data. Treat the XML and PDF as you would the original files. Nothing is uploaded; the conversion runs in your browser.
      • 
      
    • For a Heidelberg scan, select the .pdb (patient), .edb (study: scan details and layer lines) and .sdb (pictures) together. You get one XML and one PDF per series. The .edb is needed for the Thickness Grid.
      • 
      
    • The Thickness Grid (1, 3, 6 mm ETDRS) is recomputed from the ILM and BM layer lines. On the test scan it matched the Heidelberg export to within 0.001 mm. It assumes a standard lateral scale, so check it against your own export before relying on it.
      • 
      
    • Some fields of the Heidelberg export are not in these files (database UIDs, exported image paths) and are left out.
      • 
      
    • Heidelberg does not document this format, so the reader is based on open-source research.
      • 
      
    • Windows databases (Windows Search, SRUM, sysmain.sdb) are converted too. The file type is detected from its contents.
      • 
      
    • The first conversion fetches the converter (about 6 MB); later ones start straight away.
