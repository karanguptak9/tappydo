What the XML looks like

    
<database source="Windows.edb">
  <table name="SystemIndex_Gthr" columns="3">
    <columns>
      <column name="DocumentID" type="Long"/>
      <column name="FileName" type="LongText"/>
      <column name="LastModified" type="Binary"/>
    </columns>
    <row>
      <field name="DocumentID">1</field>
      <field name="FileName">report.docx</field>
      <field name="LastModified" encoding="hex">80e1c4a2f1b9d101</field>
    </row>
  </table>
</database>

    
    
      
  • The file type is detected from its contents, so the extension does not matter.
    • 
      
  • The first conversion fetches the converter (about 6 MB); later ones start straight away.
    • 
      
  • Very large databases (several hundred MB) may run out of memory on a phone. Use a row limit, or a computer.
    • 
      
  • Values stored with XPRESS9 or XPRESS10 compression cannot be decoded and are marked with an error attribute.
