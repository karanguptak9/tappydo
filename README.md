# Karan Gupta - Portfolio

A modern Next.js portfolio website showcasing professional work, experience, research papers, and projects.

**Live at:** [https://tappydo.com](https://tappydo.com)

## Features

- ✨ Modern, responsive design built with Next.js and Tailwind CSS
- 📄 Pages: About/Home, Resume, Projects, Research Papers, Contact
- 🎨 Clean, professional UI with smooth navigation
- 📱 Mobile-optimized and SEO-friendly
- ⚡ Fast performance with Next.js optimization

## Pages

- **Home/About** (`/`) - Hero section and professional introduction
- **Resume** (`/resume`) - Work experience, education, and technical skills
- **Projects** (`/projects`) - Featured projects and case studies
- **Research** (`/research`) - Published research papers
- **Contact** (`/contact`) - Contact form and social links

## Tech Stack

- **Framework:** Next.js 16 with TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
- **Version Control:** Git & GitHub

## Getting Started

### Development

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build

To build for production:

```bash
npm run build
npm run start
```

## Deployment

This project is deployed on Vercel and automatically updates on every push to the main branch.

Visit the live portfolio at [https://tappydo.com](https://tappydo.com)
